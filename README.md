**Highlights**

- PCR – Protein-to-Creatinine Ratio calculator
- INR calculator
- ESR calculator

**Technologies:** HTML · CSS · JavaScript · GitHub Pages

### 🤖 DX AI – AI Laboratory Report Analyzer

**AI-assisted laboratory report understanding**

An AI-powered project in the Zeta Dx ecosystem designed to help users explore laboratory reports through report extraction, parameter explanations, relevant calculations, and AI-generated educational insights.

**Capabilities**
- Upload laboratory reports in PDF and image formats
- Extract test names, values, units, and reference ranges
- Explain laboratory parameters in accessible language
- Support relevant unit conversions and calculations
- Present educational insights for discussion with healthcare professionals

**Technologies:** Python · FastAPI · JavaScript · HTML · CSS · OpenRouter API · LLM integration

*DX AI is an educational support tool, not a substitute for professional medical interpretation or diagnosis.*
